auto-hébergement

Les modèles à poids ouverts qu'on peut faire tourner chez soi. Choisissez votre VRAM : les trois quantisations s'affichent, en vert quand ça tient, en rouge quand l'alimentation pleure.

Modèle Labo Params VRAM Q4 VRAM Q8 VRAM FP16 $ API mélangé /M Global (AA) Ctx

VRAM = poids seuls : Q4 = params_B × 0.58 + 1.5, Q8 = params_B × 1.10 + 1.5, FP16 = params_B × 2.0 + 2.5 (Go). KV cache et overhead moteur non inclus : prévoyez de la marge, surtout à long contexte. MoE : la totalité des poids réside en VRAM, seuls les paramètres actifs comptent au compute. « taille non publiée » = poids ouverts mais architecture gardée secrète, héberger sans les dimensions, c'est acheter un meuble en ligne sans le mode d'emploi. $ API mélangé = (3·in + out)/4 sur OpenRouter, pour comparer le prix électrique au prix par token.
