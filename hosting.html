auto-hébergement

Les modèles à poids ouverts qu'on peut faire tourner chez soi. Choisissez votre VRAM : les sept quantisations s'affichent, en vert quand ça tient, en rouge quand l'alimentation pleure. Depuis la page hardware, cliquez un composant et sa mémoire s'injecte ici toute seule.

Modèle Labo Params VRAM Q2 VRAM Q3 VRAM Q4 VRAM Q5 VRAM Q6 VRAM Q8 VRAM FP16 $ API mélangé /M Global (AA) Ctx

VRAM = poids seuls, params_B × octets/poids + overhead selon la quantisation(Q2 0.33+1.0, Q3 0.42+1.2, Q4 0.58+1.5, Q5 0.70+1.5, Q6 0.82+1.8, Q8 1.10+1.5, FP16 2.0+2.5). Table complète dans data/hardware.json (_meta.quant), la même qui alimente les tok/s de la page hardware. KV cache et overhead moteur non inclus : prévoyez de la marge, surtout à long contexte. MoE : la totalité des poids réside en VRAM, seuls les paramètres actifs comptent au compute. « taille non publiée » = poids ouverts mais architecture gardée secrète, héberger sans les dimensions, c'est acheter un meuble en ligne sans le mode d'emploi. $ API mélangé = (3·in + out)/4 sur OpenRouter, pour comparer le prix électrique au prix par token.
